Cara pasang aplikasi Android

Aplikasi dipasang langsung dari file APK, bukan lewat Play Store, jadi HP akan menampilkan beberapa peringatan standar. Itu normal untuk semua aplikasi di luar Play Store. Tampilan layar bisa sedikit berbeda di tiap merek HP.

  1. 01

    Unduh file APK

    Ketuk Download APK. Jika browser bertanya apakah file ingin tetap disimpan, pilih Tetap unduh.

  2. 02

    Buka file

    Buka file dari notifikasi unduhan, atau lewat aplikasi File atau Download di HP.

  3. 03

    Izinkan pemasangan

    Jika muncul peringatan sumber tidak dikenal, ketuk Setelan, lalu aktifkan Izinkan dari sumber ini untuk aplikasi yang Anda pakai mengunduh.

  4. 04

    Pasang & buka

    Ketuk Instal. Jika Google Play Protect menampilkan peringatan, pilih Detail lalu Tetap instal. Setelah selesai, ketuk Buka.
